# Phase A Notes (Historical)

Phase A was the initial stabilisation pass. References in earlier notes to Base Actions, Quick Actions, action conversion, and 10 ft per functional leg describe the older prototype and are superseded by the current character-builder rules.

The current point-buy model, Action Point playtest rules, character JSON schema, import/export format, and known limitations are documented in [CHARACTER_BUILDER_V2.md](CHARACTER_BUILDER_V2.md).

Current limits include a two-fighter sandbox, no grid coordinates, no disengage/opportunity attacks/Overwatch, no implemented race-specific combat baselines, and no combat effects yet for skills or Willpower. These are explicit future-work items, not implemented features.
